You set the permitted scope.

Operators configure the allowed repository, workflow, branch, and image source. Agent requests must fit that scope before approval can authorize an attempt.

Know the boundary.

A separate broker identity isolates custody from the agent's OS user. The default same-user setup does not. Other agent access remains outside Opaque.

Workflow dispatch is not deployment success. The workflow and its credentials also need review; these controls apply to work routed through Opaque.
